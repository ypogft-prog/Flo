# FLO

تطبيق FLO لتوصيل الخدمات في النجف الأشرف.

## النسخة الحالية
- واجهة رئيسية وهوية FLO بالنيلي والذهبي.
- خدمات المطاعم، الصيدليات، الأدوية، الورد، الهدايا، الإكسسوارات والمتاجر.
- سلة وطلبات ومحفظة وحساب وتنقل سفلي.
- قسم FLO Taxi مع الوجهة والسعر/الدفع وحالة البحث عن السائق.
- مشروع جاهز للبناء عبر GitHub Actions وإخراج APK.

> ملاحظة: ربط Firebase والدفع والخرائط الحقيقية يحتاج إعداد بيانات المشروع ومفاتيح الخدمات لاحقاً. هذه النسخة تركز على بناء التطبيق وواجهاته وتدفقاته بدون الاعتماد على بيانات سرية داخل المستودع.
